# 正式開放前的檢查清單

網站要給陌生人用之前，資安、隱私和法務要做到的事。✓ 是已經在程式裡做好的，☐ 是只有你能做的。

## 已經做好的

- ✓ 隱私權政策 `/privacy`、服務條款 `/terms`（繁中為準、附英文版），不用登入就能看；登入卡片和首頁頁尾都有連結，登入卡片寫明「登入即表示同意」。
- ✓ 設定頁「帳號與資料」：下載我的資料（JSON）、刪除帳號（5 秒內可復原）。個資法和 GDPR 的查詢、複製、刪除權，Google Play 上架也要求 App 內能刪帳號。
- ✓ 安全標頭：禁止別的網站把本站嵌進框架（防點擊劫持）、HTTPS 強制（HSTS）、不洩漏完整網址給其他網站、只允許本站用相機。
- ✓ 原本就有：API 金鑰 AES-256-GCM 加密、資料庫全表啟用 Row Level Security、每次存取都檢查擁有者、圖片走 5 分鐘失效的簽章連結、登入後跳轉網址防釣魚（safeNext）、只用必要 Cookie（所以不需要 Cookie 同意橫幅）。

## 只有你能做的（依順序）

1. ☐ **決定營運者名義**：個人或登記行號／公司。政策裡「誰負責保管你的資料」要寫這個名字，填在主機環境變數 `LEGAL_OPERATOR`；沒填會顯示「Sheetloop 營運團隊」。要收訂閱費前建議先辦商業登記（金流商通常要求）。
2. ☐ **聯絡信箱**：主機設 `SUPPORT_EMAIL`（例如 sheetloop.app@gmail.com 或之後的網域信箱）。政策裡的刪除請求、侵權通知都寄到這裡，要有人看。
3. ☐ **請律師看過**兩份政策（特別是：未成年人與班級、著作權與分享、責任限制、管轄法院寫臺北地院是否合適）。現在的版本是依個資法和 GDPR 常見寫法的草稿，不是法律意見。
4. ☐ **網域**：買網域（例如 sheetloop.app），接到 Render，設 `SITE_URL`。Google 發布登入畫面需要驗證網域擁有權（Google Search Console）。
5. ☐ **主機**：Render 上線後，`SUPABASE_SERVICE_ROLE_KEY` 也設上，刪除帳號才會連 Google 登入帳號一起刪。步驟在 [HOSTING.md](HOSTING.md)。
6. ☐ **Google 登入發布**：Google Auth Platform → 品牌填首頁、隱私權政策、服務條款網址 → 目標對象按「發布應用程式」。
7. ☐ **AI 服務商帳號安全**：提醒使用者（或你自己測試時）在服務商後台設每月用量上限。
8. ☐ **之後才需要**：
   - 開訂閱：選金流（綠界、藍新、Stripe 等），補上購買條款、退款規則、發票；數位內容的七天鑑賞期例外要在購買前取得同意。
   - 放廣告或分析工具：要加 Cookie 同意橫幅，並更新隱私權政策。
   - 公開題庫：要有檢舉與下架流程（條款第 6 條已寫侵權通知），並注意考卷著作權。
   - 上架 Google Play：填「資料安全性」表單，內容照隱私權政策；刪除帳號網址填 `https://<網址>/settings#account`。

## 改了資料表時

新增一張存使用者資料的表，要加進 `packages/db/src/account.ts`，下載和刪除帳號才會包含它（測試會擋）。改了政策文字，要更新 `apps/web/src/features/legal/docs.ts` 的 `LEGAL_UPDATED` 日期，重大變更要先通知使用者。
